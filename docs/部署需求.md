# 化工知识超图问答库 — 部署需求

本文说明：**把整套项目从「开发机跑 API + 远端反代」改成「在一台服务器上独立运行」**时，机器、软件、网络、数据和验收必须满足什么。配套操作步骤见 [部署文档](部署文档.md)。

---

## 1. 背景与目标

当前运行方式：

| 角色                     | 现在在哪                     |
| ------------------------ | ---------------------------- |
| 向量索引 / SQLite 知识库 | 开发机`example/a/DB`       |
| 网站（登录页 + 问答台）  | 远端 nginx 静态站            |
| 开发机 → 网站机         | `autossh -R 8000` 反向隧道 |
| 大模型 / 向量 / 重排     | 独立推理机 HTTP 调用         |

隧道一断，登录页还在，问答和登录校验会 502。本次要求：

1. **API、知识库、网站同机运行**，去掉反向隧道。
2. 对外只开放 80 端口（nginx）；API 只绑本机 `127.0.0.1:8000`。

---

## 2. 范围

### 2.1 本次要迁到服务器上的

- 本仓库代码（`api/`、`src/`、配置、脚本）
- 已构建知识库 `example/a/DB`（`main.db` + `vdb/`）
- 运行配置 `example/a/config_open.yaml`
- 网站前端与 nginx 鉴权（现网在 `/root/chemical-rag-web`，不在 git 里）

---

## 3. 硬件需求

以下为**硬性门槛**。现网 VPS 若达不到，必须换机或升配后再迁，不能靠开发机隧道凑合。

| 项目           | 最低            | 推荐   | 说明                                                                                                                                                                                     |
| -------------- | --------------- | ------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **内存** | **16 GB** | 32 GB  | 当前库 pin 索引约 3 GB（chunk ~220 MB + node ~2.7 GB），SQLite`main.db` 约 4.5 GB，向量分片约 8.9 GB 会被 OS 页缓存。32 GB 用于同时放下索引、数据库页缓存、Python 进程和并发问答余量。 |
| CPU            | 8 核            | 16 核  | API 线程池默认 4；检索含向量、关键词、重排 HTTP。无 GPU 要求。                                                                                                                           |
| 系统盘         | 200 GB          | 300 GB | 系统、conda、日志。                                                                                                                                                                      |
| 数据盘         | 见下表          | 见下表 | 知识库与缓存分开更好。                                                                                                                                                                   |
| GPU            | 不需要          | 不需要 | 使用`faiss-cpu`；推理在远端。                                                                                                                                                          |
| 系统           | ubuntu          | ubuntu | 项目完全是在linux上开发                                                                                                                                                                  |

### 3.1 磁盘按搬迁内容

以当前 `example/a` 实测为基准：

| 搬迁档位      | 大约占用                                               | 数据盘建议          | 何时选                      |
| ------------- | ------------------------------------------------------ | ------------------- | --------------------------- |
| 整项目 + 缓存 | 全仓库当前约**134 GB**（其中 `cache/` ~89 GB） | **≥ 300 GB** | 完整搬家，保留 LLM/嵌入缓存 |

## 4. 软件需求

| 软件     | 版本要求                    | 用途                                               |
| -------- | --------------------------- | -------------------------------------------------- |
| 操作系统 | Ubuntu 22.04 / 24.04 x86_64 | 与现网 nginx 环境一致                              |
| Conda    | Miniconda / Anaconda        | 隔离 Python 环境                                   |
| Python   | **3.13**              | 运行 API                                           |
| 依赖     | 仓库`requirements.txt`    | FastAPI、uvicorn、faiss-cpu、pymupdf、langgraph 等 |
| nginx    | 1.24+                       | 静态站 + Basic Auth + 反代 API                     |
| systemd  | 系统自带                    | API 开机自启、崩溃拉起                             |
| curl     | 系统自带                    | 验收                                               |

`uvicorn` **必须 `--workers 1`**。多 worker 会在多个进程里各 pin 一份 FAISS，内存翻倍且结果不一致。

# 化工知识超图问答库 — 部署文档

按本文把项目装到**一台服务器**上独立运行（conda + systemd，不用 Docker）。用镜像打包请看 [Docker 部署](Docker部署.md)。硬件与验收以 [部署需求](部署需求.md) 为准。内存不足 32 GB 时不要继续。

文中默认：

- 业务用户：`root`（可改成独立用户，路径一并替换）
- 项目目录：`/root/projects/Chemical-Graph-RAG`
- 网站目录：`/root/chemical-rag-web`（源）→ `/var/www/chemical-rag`（nginx 根）
- API：本机 `127.0.0.1:8000`，`workers=1`
- 对外：`http://<服务器IP>/`

## 0. 部署后的结构

```text
浏览器
  │  80
  ▼
nginx
  ├─ /                 静态登录页 / 问答台
  └─ /api/*            Basic Auth → 127.0.0.1:8000
                              │
                              ▼
                     uvicorn (workers=1)
                     DHMF + FAISS + SQLite
                              │
                              ▼
                     推理机 113.108.154.212
                     :8030 聊天    :9998 向量/重排
```

不要再使用 `autossh -R 8000`。8000 必须是本机 uvicorn 占用。

## 1. 系统包

```bash
apt-get update
apt-get install -y nginx python3-venv build-essential git rsync curl
```

后面用 conda 跑 Python 3.13，系统 `python3` 只作辅助。

## 2. Conda 与 Python 环境

开发机现网环境名为 `test`，Python **3.13**。服务器上建议同名，避免文档和脚本对不上。

```bash
# 若尚未安装 Miniconda
curl -fsSL https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh -o /tmp/miniconda.sh
bash /tmp/miniconda.sh -b -p /root/miniconda3
source /root/miniconda3/etc/profile.d/conda.sh
conda create -y -n test python=3.13
conda activate test
```

同步代码后再装依赖：

```bash
cd /root/projects/Chemical-Graph-RAG
source /root/miniconda3/etc/profile.d/conda.sh
conda activate test
pip install -r requirements.txt
```

验证：

```bash
python -V                    # 应为 3.13.x
python -c "import faiss, fastapi, uvicorn; print('ok')"
```

## 4. 同步项目文件

在**开发机**上执行 rsync。先保证开发机 API 已停，或至少不要在同步 `DB` 时写入。

把下面的 `SERVER` 换成服务器 IP 或 SSH 别名。

### 3.1 整项目

```bash
# 开发机
SERVER=root@<服务器IP>
rsync -aH --info=progress2 \
  --exclude '__pycache__/' \
  --exclude '.git/' \
  /root/projects/Chemical-Graph-RAG/ \
  "$SERVER:/root/projects/Chemical-Graph-RAG/"
```

当前全量大约 **134 GB**（含 `cache/` ~89 GB、`example/a` ~45 GB），第一次会跑很久，需要稳定 SSH。

### 3.2 网站前端

网站前端文件在`/chemical-rag-web`。

## 4. 配置

编辑 `/root/projects/Chemical-Graph-RAG/example/a/config_open.yaml`：

- `settings.working_path` 保持 `example/a`
- `settings.base_url`、`retrieve.base_url`、`vectorization.base_url` 等指向**推理机**，不要改成 `127.0.0.1`

API 用环境变量指定配置，不要改代码：

```bash
export DHMF_CONFIG=/root/projects/Chemical-Graph-RAG/example/a/config_open.yaml
```

相对路径也可以：`example/a/config_open.yaml`。

## 5. 用 systemd 托管 API

先手动试启动一次，确认能起来再写成服务。

```bash
cd /root/projects/Chemical-Graph-RAG
source /root/miniconda3/etc/profile.d/conda.sh
conda activate test
export DHMF_CONFIG=example/a/config_open.yaml
uvicorn api.app:app --host 127.0.0.1 --port 8000 --workers 1
```

日志里应依次出现：

1. `Start pin_retrieve_indexes`
2. chunk / node pin 完成（当前 node 约 40–60 秒）
3. `Application startup complete`
4. `Uvicorn running on http://127.0.0.1:8000`

另开一个 SSH：

```bash
curl -sS http://127.0.0.1:8000/health
# 期望：{"ok":true,"config_path":"...","working_path":"example/a"}
```

Ctrl+C 停掉后，写入服务：

```bash
cat >/etc/systemd/system/chemical-rag-api.service <<'EOF'
[Unit]
Description=Chemical Graph RAG API
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/projects/Chemical-Graph-RAG
Environment=DHMF_CONFIG=example/a/config_open.yaml
ExecStart=/root/miniconda3/envs/test/bin/uvicorn api.app:app --host 127.0.0.1 --port 8000 --workers 1
Restart=always
RestartSec=5
TimeoutStartSec=180
LimitNOFILE=65535

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now chemical-rag-api
systemctl status chemical-rag-api --no-pager
```

看启动是否完成：

```bash
journalctl -u chemical-rag-api -f
```

等到 `Application startup complete` 后再测 `/health`。

**禁止**把 `--workers` 改成大于 1，也禁止再开第二个 uvicorn。端口只能有一个进程。

若 8000 已被 `sshd` 占用（旧反向隧道残留）：

```bash
ss -lntp | grep 8000
# 若是 sshd：到开发机停掉 autossh，或在本机杀掉对应 sshd 转发后再启动 API
```

## 7. 网站与 nginx

### 7.1 登录凭据

```bash
mkdir -p /root/chemical-rag-web
cat >/root/chemical-rag-web/config.json <<'EOF'
{
  "username": "admin",
  "password": "请改成实际密码"
}
EOF
chmod 600 /root/chemical-rag-web/config.json
```

### 7.2 静态页

若已从旧机同步了 `/root/chemical-rag-web/web/`，跳到 7.3。

登录页标题须为「化工知识超图问答库」。源码在 `web/index.html` 的 `<title>` 与 `<h1>`。

### 7.3 生成 htpasswd 并发布静态文件

把下面存为 `/root/chemical-rag-web/apply-auth.sh` 后执行。若旧机已有此脚本，直接用旧的。

```bash
cat >/root/chemical-rag-web/apply-auth.sh <<'EOF'
#!/bin/bash
set -euo pipefail
ROOT=/root/chemical-rag-web
WEB_DST=/var/www/chemical-rag
HTPASSWD=/etc/nginx/chemical-rag.htpasswd
CFG="$ROOT/config.json"

python3 - "$CFG" "$HTPASSWD" <<'PY'
import json, hashlib, base64, sys, pathlib
cfg_path, out_path = sys.argv[1], sys.argv[2]
cfg = json.loads(pathlib.Path(cfg_path).read_text(encoding="utf-8"))
user = str(cfg.get("username") or "").strip()
pw = str(cfg.get("password") or "")
if not user or not pw:
    raise SystemExit("config.json 里 username / password 不能为空")
if ":" in user:
    raise SystemExit("username 不能包含冒号")
digest = base64.b64encode(hashlib.sha1(pw.encode("utf-8")).digest()).decode("ascii")
pathlib.Path(out_path).write_text(f"{user}:{{SHA}}{digest}\n", encoding="utf-8")
print(f"updated {out_path} (user={user})")
PY

chown root:www-data "$HTPASSWD"
chmod 640 "$HTPASSWD"
chmod 600 "$CFG"

mkdir -p "$WEB_DST"
if [[ -d "$ROOT/web" ]]; then
  rm -rf "$WEB_DST"/*
  cp -a "$ROOT/web/." "$WEB_DST/"
fi
chown -R root:www-data "$WEB_DST"
find "$WEB_DST" -type d -exec chmod 755 {} \;
find "$WEB_DST" -type f -exec chmod 644 {} \;

nginx -t
systemctl reload nginx
echo "nginx reloaded."
EOF
chmod +x /root/chemical-rag-web/apply-auth.sh
```

### 7.4 nginx 站点

写入 `/etc/nginx/sites-available/chemical-rag`（把 `server_name` 换成实际 IP 或域名）：

```nginx
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name <服务器IP> _;

    root /var/www/chemical-rag;
    index index.html;

    server_tokens off;
    client_max_body_size 1m;

    proxy_connect_timeout 180s;
    proxy_send_timeout    900s;
    proxy_read_timeout    900s;
    send_timeout          900s;
    proxy_http_version 1.1;

    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header Referrer-Policy "same-origin" always;

    location = /robots.txt {
        default_type text/plain;
        return 200 "User-agent: *\nDisallow: /\n";
    }

    location ^~ /api/ {
        auth_basic           "Restricted";
        auth_basic_user_file /etc/nginx/chemical-rag.htpasswd;

        proxy_set_header Host              $host;
        proxy_set_header X-Real-IP         $remote_addr;
        proxy_set_header X-Forwarded-For   $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header Authorization     "";

        location = /api/health {
            proxy_pass http://127.0.0.1:8000/health;
        }
        location = /api/query {
            proxy_pass http://127.0.0.1:8000/query;
        }
        location = /api/multihop-query {
            proxy_pass http://127.0.0.1:8000/multihop-query;
        }
        location = /api/agentic-query {
            proxy_pass http://127.0.0.1:8000/agentic-query;
        }
        location = /api/retrieve {
            proxy_pass http://127.0.0.1:8000/retrieve;
        }
        location = /api/stream {
            proxy_pass http://127.0.0.1:8000/stream;
            proxy_buffering off;
            proxy_cache off;
            proxy_set_header Connection "";
            chunked_transfer_encoding on;
        }

        return 404;
    }

    location = /health          { return 404; }
    location = /query           { return 404; }
    location = /multihop-query  { return 404; }
    location = /agentic-query   { return 404; }
    location = /retrieve        { return 404; }
    location = /docs            { return 404; }
    location = /redoc           { return 404; }
    location = /openapi.json    { return 404; }

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

启用站点（与默认欢迎页不能同时占 `default_server`）：

```bash
rm -f /etc/nginx/sites-enabled/default
ln -sfn /etc/nginx/sites-available/chemical-rag /etc/nginx/sites-enabled/chemical-rag
bash /root/chemical-rag-web/apply-auth.sh
```

`apply-auth.sh` 末尾会 `nginx -t` 并 reload。若静态页还没有，先把 `web/` 拷进 `/root/chemical-rag-web/web/` 再跑一次。

# 化工超图知识图谱系统总结报告

**系统名称：** 化工超图知识图谱系统（Chemical-Graph-RAG）
**作答与评判模型：** llm-medium
**对照基线：** 不查阅资料的纯语言模型；通用企业知识库系统 WeKnora（智能体快速问答）

---

## 一、项目介绍

本报告说明化工超图知识图谱系统的建成形态、库内规模和已完成评测的主要结论。系统服务于化工产品资料的建库、检索与问答，语料包括产品技术数据表、专利文献和化学品安全数据表。这类资料以扫描件和版式复杂的表格为主，需要核对的内容往往是牌号、化学文摘登记号、含量、粘度、配比和储存条件等短字段。

**（一）资料如何进入知识库**

原始文件先识别为中文正文，数值、单位和登记号按原文保留。每一份资料再写成一段产品摘要，概括品名、型号、关键规格、用途和厂家。摘要把该篇资料上的信息收成一个整体；正文则切成可供检索的文本块。从正文中抽出的品名、型号、成分、规格、用途、包装储存和生产厂家，各自成为一条实体记录。长文档按页拆成多段分别入库，内容相同的文件不重复写入。

**（二）知识如何组织**

摘要是这条资料的超边，本篇抽出的实体都挂在它下面。查阅某个实体时，可以同时看到同一篇资料上的其他实体，用来对照规格、成分和储存条件。实体之间的关联以整篇资料为单位：同一篇里的牌号、成分和指标可以互相核对。检索据此按标识和指标找回原文中的实体，再在同一篇资料内完成对照。

**（三）问题如何回答**

检索同时走三条路径：与问题相近的正文、与问题相近的实体，以及牌号、登记号等少见标识的精确匹配。命中结果合并后，再挑选更相关的片段，并按所属资料补足上下文，交给模型组织回答。在线问答采用多轮检索：模型根据问题决定继续查库、阅读原文或核对同篇实体，然后给出回答。

**（四）当前完成范围**

TDS、专利和MSDS均已完成全部文件的处理。在线站点已提供技术数据表与专利范围内的问答。安全数据表已进入同一知识库，因其体量较大，生产环境尚未将其载入内存。下文依次给出库内规模、在线站点、响应速度，以及两组正确率评测：一组在全量安全数据表上与纯语言模型比较，一组在同一批原始文档上与 WeKnora 比较。

## 五、安全数据表上的正确率

| 项       | 内容                                                        |
| -------- | ----------------------------------------------------------- |
| 文档范围 | 安全数据表全部切片，共 200 577 条                           |

| 作答     | 本系统多轮检索；同一模型不查阅资料                          |
| 评判     | llm-medium，成对比较                                        |
| 墙钟     | 111 206 秒（30.89 小时），逐题顺序作答                      |

### 5.4 文档召回与本节时延的含义

文档召回按标准答案所依据的文档是否出现在检索来源中计算。全部命中指这些文档都出现，部分命中指只出现一部分，未命中指都未出现。

| -------- | ---: | -----------: | -----------: | -------: |
| 全部命中 |   35 |           34 |            1 |        0 |
| 部分命中 |   42 |           42 |            0 |        0 |
| 未命中   |  123 |          112 |           10 |        1 |

标准文档未被召回而回答仍判为正确的有 112 题。安全数据表中，同一事实可能出现在相邻切片或同篇其他实体的描述里，正确作答可以建立在这些部分证据上。平均文档召回 26.75%，与 94.47% 的回答正确率描述的是两件不同的事。

本节每问平均 512.55 秒，其中实体检索 449.82 秒。这是开发环境上对全量安全数据表逐片检索的耗时。它与第四节在线入口、技术资料与专利范围内的抽样是两次测量：第四节的检索中位数为 6.72 秒，端到端中位数为 61.66 秒。

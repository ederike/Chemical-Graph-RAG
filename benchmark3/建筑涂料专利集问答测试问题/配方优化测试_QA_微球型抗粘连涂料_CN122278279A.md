## 一、测试问题

我们厂做保温装饰一体板，水性弹性丙烯酸涂料辊涂下线后覆 PE 保护膜，叠压码垛入库。天热堆放一两周后问题来了：**揭膜时漆膜跟着膜被撕下来，板与板叠压面也互相粘连掉漆**，废板率很高。乳液 Tg 偏低、漆膜偏软这个改不了（板子要弯折）。加蜡粉以前试过，表面会沾油污。不想上双组分。从配方上怎么解决？

## 二、参考答案 · 解决机理

**核心思路：物理 + 化学双重作用，替代蜡系 / 氟系表面处理。**

### 1. 物理作用 —— 微球把「面对面」变成「点对面」（主治粘连）

- 引入**改性球形微珠**（玻璃/陶瓷，D90 60–80 μm）+ 填料，漆膜干燥后表面微观呈**半球状凹凸**；
- 揭膜、板间叠压时**接触面大幅降低、粘连面积变小**，剥离撕拉力集中在微球凸点上，漆膜本体不被破坏（\[0029]）；
- 本质区别于「提高漆膜硬度」路线：**不依赖漆膜变硬，Tg 不动、弯折性保留**——正好满足本题约束。

### 2. 化学作用 —— 低表面能链段降粘附（主治耐污）

- **改性聚丙烯酸**（聚丙烯 + 丙烯酸 + 马来酸酐接枝反应制得）包裹填料；
- 聚丙烯链段惰性、**低表面能**，污垢难以附着、易清除；
- 其中的聚丙烯酸结构与丙烯酸乳液基体亲和，充当**相容剂**，改善大量填料在体系中的分散与结合（\[0031]）。

### 3. 协同交联 —— 为什么必须改性，不能简单共混

| 改性步骤         | 作用                                       | 专利证据                    |
| ------------ | ---------------------------------------- | ----------------------- |
| 微珠 KH-560 改性 | 改善分散 + 引入环氧活性基团，微珠「锚」在漆膜里，撕膜时不脱落         | 对比例 1：未改性 → 分散/结合差，性能下降 |
| 聚丙烯接枝 AA/MAH | 羧基与微珠环氧基通过化学键/氢键形成**网络结构**，软漆膜但有「网络骨架」抗撕 | 对比例 2：纯聚丙烯 → 包覆/相容性不足   |
| S3 预反应工序     | 改性聚丙烯酸充分包覆填料并与微珠交联                       | 对比例 3：跳过 S3 → 耐沾污显著劣化   |

## 四、参考答案 · 制备工艺（S1–S4）

### S1 硅烷改性微珠

乙醇 : 水 = 9:1（质量比）配溶剂，按溶剂 5 wt% 加入 KH-560 环氧基硅烷偶联剂，乙酸调 pH 至 5.0，搅拌 30 min 得水解液；加入球形微珠（微珠 : KH-560 = 2:1），**80℃ 搅拌反应 4 h**，过滤、干燥。
（温度区间 60–80℃，时间 2–4 h）

### S2 制备改性聚丙烯酸

5 份聚丙烯（中石化 T30S）+ 35 份去离子水 + 5 份二甲苯，85℃ 加热溶胀 10 min；加入 0.075 份 BPO 引发剂、1.5 份马来酸酐、1.5 份丙烯酸，**氮气氛围下 95℃ 搅拌反应 3 h**，洗涤、过滤、干燥。
（聚丙烯 : 丙烯酸 : 马来酸酐 = (5–10):(1–2):(1–2)，质量比）

### S3 制备中间产物（关键工序，不可省）

按配方份数将**改性球形微珠 + 填料 + 改性聚丙烯酸 + 水**混合，**85℃ 搅拌 4 h**，使改性聚丙烯酸充分包覆填料并与微珠交联。
（温度区间 80–100℃，时间 3–6 h；对比例 3 证明跳过此步性能显著劣化）

### S4 调漆（四步法）

1. **预混合**：分散缸加 15–18 份水，500–600 RPM 下依次加入分散剂、成膜助剂、防冻剂、纤维素醚、pH 调节剂，混成凝胶状液；
2. **研磨**：加钛白粉，1200–1500 RPM 高速研磨 15–20 min，**细度 ≤50 μm 合格**；
3. **调漆**：加丙烯酸乳液、防腐剂、消泡剂，600–800 RPM 搅 5–10 min；
4. **加中间产物**：转速降至 500–600 RPM **缓慢加入 S3 中间产物**（防止微珠破碎），随后加入其余成分，搅 10–15 min，送检。

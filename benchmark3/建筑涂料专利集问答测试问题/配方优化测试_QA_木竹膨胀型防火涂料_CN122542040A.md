> **测试目标**：验证知识库能否基于「现场痛点描述（不含专利术语）」检索专利并给出配方级解决方案
>
> **来源专利**：CN 122542040 A《一种木竹建材专用环保膨胀型防火涂料》（湖南麓上住宅工业科技有限公司，申请号 202610833511.4，公开日 2026-08-11）

> **答案依据**：权利要求书 1–10 + 说明书 \[0002]–\[0054] + 实验一至实验四 \[0055]–\[0082] + 制备与施工 \[0083]

## 一、测试问题

> 我们厂在南方做竹集成材构件（景观廊架、格栅板、栈道板），出厂前辊一道水性防火涂层。问题出在安装后头一年：梅雨季加夏天暴晒来回几轮，涂层跟竹材表面开始脱粘，先是边角起壳，后来成片往下掉，刀一撬整块就揭得下来，露出光滑的竹青面，复检时耐火时间比出厂值掉了一大截。换过两三款市售的水性封闭底漆先打底再辊防火涂层，照样从底漆和竹面之间脱开。也试过把防火涂层里乳液比例加大、想裹得更牢，结果烧的时候炭层发虚、耐火时间反而更短。从配方和涂层结构上怎么解决？

**命题设计说明**

| 设计点   | 说明                                                 |
| ----- | -------------------------------------------------- |
| 痛点    | 单一场景（户外干湿循环后涂层与竹材脱粘、成片脱落 → 防火保护失效），对应专利背景技术 \[0003] 第一缺陷"与木竹基材界面结合力弱，长期使用或温湿度变化易脱粘脱落" |
| 负约束 1 | 「市售水性封闭底漆打底照样脱」→ 拦截"换普通丙烯酸底漆"答案（实验一组 3 \[0058]：去除渗透锚固单体后附着力 2 级、界面结合强度 0.8MPa） |
| 负约束 2 | 「加大乳液比例裹得更牢 → 炭层发虚」→ 拦截"提高成膜物用量"答案（\[0026]/\[0028]：第二成膜单体 >18 份稀释阻燃成分、阻燃体系 <40 份炭层强度不足） |
| 检索难点  | 题干不含「膨胀型」「木竹建材」「锚固」「互穿网络」「核壳」「聚磷酸铵」等锚词，需靠「竹青面 / 刀一撬整块揭下来 / 复检耐火时间掉」与背景技术段语义对齐 |

## 二、参考答案 · 问题诊断与解决机理

### 1. 问题诊断

- **症状定位**：专利 \[0003] 第一缺陷——现有木竹用防火涂料**与基材界面结合力弱，长期使用或受温湿度变化影响易脱粘、脱落**；涂层一旦脱粘，防火保护即告失效（"复检耐火时间掉了一大截"正是其后果，\[0002]）。
- **竹材特殊性**：竹青面光滑致密，普通水性底漆只能物理吸附 + 浅表机械咬合；干湿循环叠加竹木吸湿胀缩，界面应力累积后成片脱开。
- **已试路线为何失败**：
  - 换市售水性封闭底漆：缺少能与木竹**纤维素羟基共价键合**的组分 → 实验一组 3（\[0058]）：附着力 0 级 → 2 级、界面结合强度 2.1 → 0.8MPa、氧指数 27% → 23%；
  - 加大乳液用量：\[0026] 第二成膜单体 >18 份会**稀释阻燃成分**、降低防火性能；\[0028] 改性膨胀阻燃体系 <40 份**无法形成足够厚度和强度的膨胀炭层**——牺牲防火性能换"包裹感"是假解。

### 2. 核心机理：三层梯度结构 + 界面共价键合网络（\[0016]）

1. **锚固底层治"脱"**：含磷酸酯基团的丙烯酸酯类**渗透锚固单体**渗入木竹基材表面孔隙，与木竹**纤维素羟基形成共价键合**（\[0025]）——把"物理贴附"变成"化学锚固"；磷酸酯基团兼具阻燃协效，提升界面防火性能；第一成膜单体**硬单体质量 > 软单体**（甲基丙烯酸甲酯 6 / 丙烯酸丁酯 3 / 丙烯酸 1），保证底层刚性与高温稳定性（\[0024]；实验一组 5：软 > 硬时 200℃ 软化流淌）。
2. **层间化学缝合**：阻燃层**内交联单体**（1,6-己二醇二丙烯酸酯 + 三丙二醇二丙烯酸酯复配）未完全反应的**端基双键**，与锚固底层残留的磷酸酯基团、耐候面层的活性基团发生**界面共价键合**（权利要求 1 / \[0027]）——三层不是简单叠涂，而是被化学缝合成一体的交联网络。
3. **可聚合乳化剂防迁移**：2-丙烯酰胺基-2-甲基丙磺酸钠 / 烯丙基聚氧乙烯醚硫酸铵参与共聚、化学键合到聚合物分子链上，**避免传统乳化剂成膜过程中迁移到涂层表面**导致耐水性下降、附着力降低（\[0052]；实验一组 4：普通乳化剂路线乳液分层沉淀、附着力 1 级、耐水严重起泡脱落）。
4. **面层界面增强**：硅烷偶联剂复配物（γ-甲基丙烯酰氧基丙基三甲氧基硅烷 : γ-缩水甘油醚氧丙基三甲氧基硅烷 = 7:3）提升耐候面层与阻燃层的界面结合力（\[0033]；实验三组 3：无偶联剂 → 与阻燃层脱粘）。
5. **阻燃层本体协同**（治"裹不牢 / 炭层发虚"的正解）：复配内交联单体经分步自由基加成聚合形成**梯度互穿网络**（\[0027]/\[0037]）；硅酸铝短切纤维（优选长 75μm、径 6~8μm）受火时与聚磷酸在膨胀炭层中形成**无机纤维增强三维网络**（\[0039]/\[0040]/\[0042]）；聚磷酸铵以可聚合硅烷偶联剂为壁材**微胶囊包覆**（包覆率 6~9%）并与内交联单体共聚、化学键合入网络，避免团聚迁移析出（\[0039]/\[0041]）。

## 四、参考答案 · 制备工艺与验证标准

### S1 锚固底层乳液（种子乳液聚合，\[0083]）

第一成膜单体 + 渗透锚固单体 + 可聚合乳化剂与去离子水混合均匀，加入引发剂进行种子乳液聚合反应，**75~85℃ 反应 4~6h**，得锚固底层乳液。

### S2 阻燃层浆料（分步自由基加成聚合，**分步投料不可省**，\[0083]/\[0037]）

第二成膜单体 + 内交联单体 + 可聚合乳化剂与去离子水混合均匀，加入引发剂进行分步自由基加成聚合：**先加入 1,6-己二醇二丙烯酸酯，25~35℃ 反应 2~3h**，**待其转化率达到 85% 以上时**，**再加入三丙二醇二丙烯酸酯继续反应 1~2h**（优选温度 30℃、优选总反应时间 4h），得基础乳液；再向基础乳液中加入改性膨胀阻燃体系 + 无机填料 + 环保助剂，**高速分散 30~45min**，得阻燃层浆料。

（分步投料不可省：\[0037] 明确——转化率低于 85% 就加入三丙二醇二丙烯酸酯，两种单体同时反应、无法形成梯度互穿网络结构，抗开裂性能下降；实验二组 5 证明单一 HDDA 路线弯曲 0.5mm 即开裂。）

### S3 耐候面层乳液（\[0083]）

核壳结构丙烯酸酯乳液 + 硅烷偶联剂 + 常温自交联单体 + 壳聚糖季铵盐-纳米氧化锌复合抗菌剂 + 可聚合乳化剂与去离子水混合均匀，**高速分散 20~30min**，得耐候面层乳液。

### S4 施工（\[0083]）

木竹表面**清洁打磨**（去除灰尘与油污）→ 依次涂覆**锚固底层 → 阻燃层 → 耐候面层**，**每道涂层干燥后再涂覆下一道**，涂层总厚度按耐火极限要求确定，一般为 **1.5~3mm**；养护条件 25℃、相对湿度 60%、养护 7d（实验条件 \[0056]/\[0077]）。

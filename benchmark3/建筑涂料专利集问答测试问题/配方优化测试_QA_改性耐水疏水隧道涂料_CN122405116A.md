## 1. 测试问题

> 我们是高速公路隧道养护单位的，管着南方山区一组长隧道的土建养护。洞里湿度大，侧壁和拱圈常年渗水，冷凝水顺着墙面成片往下淌。现在用的环氧类防腐涂层，两三年就开始吸水发软、表面泛白，接着鼓包，最后成片从墙皮上撕脱，检修道一侧最严重。趁今年整体翻新想从配方上根治。以前把普通环氧防腐漆加厚多刷两遍，撑不过一个雨季就又鼓；往漆里掺粉料堵孔隙的路子也试过，水膜照样贴着墙面铺开。从配方上怎么解决？

## 2. 解决机理

### 2.1 问题归因

传统隧道用环氧涂料**表面能较高、疏水性不足**：隧道壁上的冷凝水或渗漏水极易铺展、润湿涂层表面，并渗入涂层与基材的界面，为水汽和侵蚀离子提供通道，长期使用后涂层**增重、软化、附着力严重下降，从基材上脱落**（[0002]）。传统路线失败原因：加厚涂刷普通环氧漆不改变表面润湿行为（对比例 1，[0026]）；只掺无机粉料堵孔隙而不降低表面能，水膜照样铺展润湿（对比例 2，[0027]）。

### 2.2 核心机理：低表面能 + 表面微观粗糙度协同，构建超疏水表面

1. **化学降表面能**（氟化环氧基荧光素螺内酰胺化合物）：分子结构上含有**大量氟原子和环状结构**，赋予优异的化学稳定性和疏水性，**显著降低涂料的表面能**（[0018]/[0019]）。
2. **物理建粗糙度**（改性石墨烯 + 改性二氧化硅）：构建涂料的**表面微观粗糙度**，与低表面能结合，赋予涂料优异的耐水疏水性能，**形成超疏水表面，有效阻止水分侵入**（[0018]）。
3. **化学键锚定（区别于物理共混）**：
   - 氟化化合物上**多个环氧基团**参与固化交联反应，以化学键的形式分布于涂层中，稳定长效（[0019]）；
   - 改性石墨烯：KH-560 硅氧烷水解形成硅醇接枝到氧化石墨烯表面并引入环氧基团 → **均匀分散 + 化学键连接**稳定存在于涂层；氧化石墨烯二维片状结构、高比表面积、优异阻隔性能，**有效抑制腐蚀介质侵蚀**（[0020]）；
   - 改性二氧化硅：KH-792 接枝引入**氨基/亚氨基基团**实现化学键连接、均匀填充；纳米二氧化硅粒径小（平均 10nm），**填充涂层微缝隙缺陷、提高致密程度，阻碍腐蚀介质侵蚀**（[0021]）。

### 2.3 对比例证据（三种改性剂缺一不可）

| 对比例 | 变量 | 结果 | 依据 |
|---|---|---|---|
| 对比例 1 | 三种改性剂全不加（纯环氧体系，即"加厚涂刷"路线） | 耐水疏水性能显著劣于实施例 | [0026]/[0033] |
| 对比例 2 | 只加改性石墨烯+改性二氧化硅，无氟化化合物（即"只堵孔不降表面能"路线） | 显著劣于实施例，水膜仍铺展润湿 | [0027]/[0033] |
| 对比例 3 | 只加氟化化合物+改性二氧化硅，无改性石墨烯 | 显著劣于实施例，缺二维片层高阻隔 | [0028]/[0033] |
| 对比例 4 | 只加氟化化合物+改性石墨烯，无改性二氧化硅 | 显著劣于实施例，缺纳米填充致密化 | [0029]/[0033] |

> 说明：实施例/对比例具体性能数值在专利 [0032] 结果表中为图像，pdftotext 无法提取；对比结论引自文字段 [0033]。

## 4. 制备工艺（S1–S7，实施例 2 点值 + 权利要求区间）

- **S1 制备氨基荧光素螺内酰胺化合物**：10mmol 荧光素 + 22mmol 1,3,5-三氨基苯 + 75mL 乙醇入三口烧瓶，氮气保护，**22℃、250r/min 搅拌 25min**，升温 **85℃ 反应 7h**；冷却至室温 → 旋转蒸发除溶剂 → 倒入冰水 → 真空抽滤，滤饼以淋洗剂 A（**二氯甲烷:乙醇 = 19:1** 体积比）硅胶柱层析纯化。
  （区间：20–25℃ 预搅 20–30min、80–90℃ 反应 6–8h；投料比 荧光素:1,3,5-三氨基苯:乙醇 = 10mmol:20–25mmol:70–80mL；淋洗剂 A 18–20:1；权利要求 2、[0005]–[0007]）
- **S2 制备氟化荧光素螺内酰胺化合物**：10mmol S1 产物 + 32mmol 三乙胺 + 22mmol 全氟丁基磺酰氟 + 95mL 二氯甲烷，氮气保护，**3℃、250r/min 搅拌 1.5h**，升温 **22℃ 反应 4.5h**；真空抽滤 → 滤液旋蒸 → 乙醇、丙酮依次洗涤 2 次 → **55℃ 真空干燥 3h**。
  （区间：0–5℃ 1–2h、20–25℃ 4–5h；投料比 10mmol:30–35mmol:21–23mmol:90–100mL；干燥 50–60℃ 2–4h；权利要求 3、[0008]）
- **S3 制备氟化环氧基荧光素螺内酰胺化合物（关键工序，不可省——环氧基团是化学键锚定于涂层的前提）**：10mmol S2 产物 + 32mmol 碳酸钾 + 145mmol 环氧氯丙烷，氮气保护，**22℃、250r/min 搅拌 25min**，升温 **115℃ 反应 8h**；冷却至室温 → 倒入乙酸乙酯:蒸馏水 = **1:1** 混合溶剂静置分层 → 有机相硫酸钠干燥 → 真空抽滤 → 旋蒸 → 淋洗剂 B（**石油醚:乙酸乙酯 = 2.5:1** 体积比）柱层析纯化。
  （区间：20–25℃ 预搅 20–30min、110–120℃ 反应 6–10h；投料比 10mmol:30–35mmol:140–150mmol；淋洗剂 B 2–3:1；权利要求 4、[0009]/[0010]）
- **S4 制备改性石墨烯（不可省，对比例 3 证明缺此组分性能显著劣化）**：7.5g KH-560 + 35mL 蒸馏水 + 65mL 乙醇，氮气保护，**22℃、250r/min 搅拌 25min**，乙酸调 **pH 3.5** 继续搅 25min，加 1g 氧化石墨烯升温 **85℃ 反应 6h**；冷却 → 真空抽滤 → 蒸馏水洗 2 次 → **55℃ 真空干燥 3h**。
  （区间：KH-560:蒸馏水:乙醇:氧化石墨烯 = 5–10g:30–40mL:60–70mL:1g；pH 3–4；80–90℃ 5–7h；干燥 50–60℃ 2–4h；权利要求 5/6、[0011]–[0013]）
- **S5 制备改性二氧化硅（不可省，对比例 4 证明缺此组分性能显著劣化）**：2g 纳米二氧化硅（平均粒径 10nm）+ 4g KH-792 + 85mL 乙醇，氮气保护，**22℃、250r/min 搅拌 25min**，质量分数 1.5% 盐酸调 **pH 3.5**，升温 **75℃ 反应 6h**；冷却 → 真空抽滤 → 蒸馏水洗 2 次 → **55℃ 真空干燥 4h**。
  （区间：纳米二氧化硅:KH-792:乙醇 = 2g:2–6g:80–90mL；盐酸质量分数 1–2%；pH 3–4；70–80℃ 5–7h；干燥 50–60℃ 3–5h；权利要求 7/8、[0014]–[0016]）
- **S6 称量**：按 3.2 配方表称取环氧树脂 E-51、丁基缩水甘油醚、氟化环氧基荧光素螺内酰胺化合物、改性石墨烯、改性二氧化硅、消泡剂 BYK-066N、聚醚胺 D230、2,4,6-三（二甲胺基甲基）苯酚，备用。
- **S7 调漆（两段控温，权利要求 9、[0017]）**：将 E-51、丁基缩水甘油醚、氟化化合物、改性石墨烯、改性二氧化硅、BYK-066N 加入混合机，**45℃、800r/min 搅拌反应 40min**；降温至 **22℃** 加入聚醚胺 D230、2,4,6-三（二甲胺基甲基）苯酚，继续搅拌 **25min**，得成品。
  （区间：前段 40–50℃、600–1000r/min、30–50min；降温至 20–25℃；后段 20–30min）
